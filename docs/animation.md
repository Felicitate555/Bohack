# 动画与音乐实现

高质量路径采用项目内置的 HTML Canvas 动画组件，通过 Playwright 控制 Chromium 按明确时间逐帧截图，FFmpeg 编码；没有执行 AI 输出的程序代码。HyperFrames 同样支持逐帧浏览器渲染，但当前选用这条更小的 Python 集成路径，避免再引入 Node CLI 与第二套运行时。没有 Playwright / Chromium 时，可选择原有 Pillow 轻量路径。

场景包含结构化参数、视觉元素和类型、布局、安全区、动画动作与关键帧、节拍标记、样式、素材与实际起止时间。用户可编辑标题、旁白、类型、数量、比例、公式、动作说明与动画节奏；模型还可选择图形位置、关键帧起止比例和淡入淡出或硬切。关系网络可使用经校验的节点连线列表，未提供列表时展示所有两两连接。曲线和柱状图使用模型给出的元素值，未提供数据时不捏造数据。几何当前为基础多边形，复利组件使用明确本金、每期增长率和整数期数绘制复利与仅本金计息的单利对照，并逐期显示计入本金的利息；期内线段只是视觉插值，结算值按完整期数计算。最多 6 个经过范围校验的整体画面关键帧可控制位移、缩放和透明度；多段位移可表达有限的整体轨迹。点阵与关系网络支持每节点一条受限直线运动，可编辑起终位移、时间、缓动及节拍吸附；连线随节点移动，位置限制在画面内。其他独立元素的自由轨迹、专业数学公式排版、交互时间轴和自定义 AI 动画代码均未实现。

音乐经 FFmpeg 解码后计算频谱变化与能量，估计 BPM、峰值和 8 秒能量段。检测得到的瞬态点用于图形脉冲及逐步展开，强峰值有更明显的强调，镜头结束在不截断旁白的条件下向后吸附最多 0.65 秒；界面显示估计的节拍分布。结果是估计值，不保证拍点或音乐段落准确，尤其是弱节奏音乐；关键帧事件可将起止点吸附至前后 0.35 秒内的估计节拍；若会造成时间倒置则保持原时间。不足一帧的对齐误差可能存在。背景音量可调；配音存在时使用旁白信号侧链压低音乐，结束后恢复，结尾淡出，音乐短于影片时末尾静音。此混音已用合成音频和 FFmpeg 测试，尚未以真实旁白完成整片验收。整镜配音字幕按文字长度估时；逐句配音使用各句解码音频时长生成画面字幕与 SRT，仍没有逐词强制对齐。

浏览器渲染耗时显著高于旧方案，正式导出目标为 1920×1080 / 30fps，快速预览为 960×540 / 15fps。请在运行电脑上根据性能选择；此项目未完成 2GB 内存压力实测。

散射组件可通过 `parameters.optical_path` 选择 `short` 或 `long`，并可通过 `labels` 指定光源和观察者名称；工作台可修改光程。短光程示意短波散射，长光程示意透射光偏暖。光线、分子数量和路径均为定性示意，并非真实尺度、光谱或物理模拟。

节拍检测使用去均值后的频谱变化周期性作启发式评分，达到阈值且有足够瞬态时才提供估计 BPM 和可绑定节拍；低可信情况下只保留检测到的瞬态，不进行自动节拍吸附。周期性评分不是经校准的概率，也不能证明音乐拍点准确。旧版分析没有此评分，音乐仍可播放与混音，但需重新上传以重新分析并启用节拍绑定。

浏览器渲染先缓存无音轨的镜头画面，再按各镜头实际帧时长拼接和补齐旁白，最后统一编码音频并混入音乐，避免逐镜头 AAC 拼接的延迟逐段累积。旧版带音轨镜头缓存不会复用；配音缓存仍可复用。逐句模式按每句解码时长安排字幕；整镜模式按文字长度估时，两者均非词级强制对齐。

不重复概率组件使用类别数和抽取次数计算逐次条件概率、累计不重复概率与互补概率；前提是独立、等概率、允许重复抽取，画面会标明假设。离线生日示例以 365 类、23 次展示约 49.27% 与 50.73%，并保留浏览器和 Pillow 两条路径。轻量渲染仅支持部分组件，不支持的镜头会返回明确提示。

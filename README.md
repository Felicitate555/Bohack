# VibeLab · 一句话短片工作台

给创作者一个起点：输入一句想法，文本模型生成故事和镜头计划，修改后由本地动态图形引擎制作 MP4。项目处于 Bohack 基础 Demo 阶段；目前更擅长知识讲解、概念解释等图形化内容，尚不能生成任意真人剧情或电影画面。

## 快速体验

需要 Docker Desktop 并启动 Docker 服务；首次运行需要网络下载镜像。克隆仓库后：Windows 双击 `start.bat`；macOS / Linux 执行 `sh start.sh`。打开 <http://localhost:3000>，点击「没有 API？先体验生日悖论示例」，查看或修改分镜后点击「保存并生成视频」。不勾选旁白即可离线渲染示例。作品保存在 Docker volume；`stop.bat` / `sh stop.sh` 停止服务，不删除作品。

### 一句话生成分镜

打开项目根目录的 `.env`，在 `SILICONFLOW_API_KEY=` 后填写自己的硅基流动密钥。如果没有该文件，请复制 `.env.example` 为 `.env`。其他 `SF_MODEL_...` 均可按账户实际支持的模型调整。重启服务后，在「模型与 API 设置」中可选择检查连接。自定义创作和在线配音需要网络；离线示例不需要 Key。`.env` 已被 Git 忽略，不要上传或分享真实密钥。

首页可选极速、智能（编剧 + 导演）或导演级（编剧 + 旗舰导演 + 动画导演）。分镜作为后台任务保存；页面刷新后可继续查看，失败时已保存的基础分镜可继续编辑，没有分镜时可由用户主动重试并复用已保存的编剧草稿。如需生成素材，在工作台勾选素材生成，并在相应镜头选择 AI 图片或视频及填写素材描述。

勾选「生成中文旁白」后可选择硅基流动 CosyVoice2 / MOSS-TTSD 或 Edge TTS，需要网络；硅基流动配音需要 Key。关闭配音且不上传音乐时导出的是无音轨视频，画面中仍有字幕。字幕按照句段文字长度估时，**不是精确强制对齐**。事实和模型生成的数字需要人工检查。

如果配音失败，工作台应显示接口状态码和排查方向；API Key 已配置并不代表每个语音模型都有权限或账户余额充足。Edge TTS 使用另一项在线服务，不能保证在所有网络环境中可用。更改 `.env` 后需要重启本地服务或重新创建 Docker 容器。

当前没有托管体验码服务：评委如需自定义主题，需要自行配置 API；直接访问 GitHub 只提供源码，不能直接在 GitHub 上运行生成任务。私有仓库需要评委先获得访问权限，公开与否由团队决定。切勿将个人 API Key 放入仓库或前端。

## 本地开发（不使用 Docker）

需要 Python 3.11、FFmpeg / FFprobe、Chromium 或 Chrome 和系统中文字体。Windows 示例：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 3000
```

系统没有可识别中文字体时，在 `.env` 设置 `VIBELAB_FONT` 为旧轻量渲染器的中文字体文件路径。浏览器渲染使用系统字体；若浏览器不在默认位置，可通过 `VIBELAB_CHROMIUM` 指定可执行文件。其他系统使用对应虚拟环境激活命令。启动后打开 <http://127.0.0.1:3000>，更改后端代码或安装依赖后需重启服务。

## 现有能力和边界

- 一句话调用可配置的文本模型生成 1–16 个结构化镜头；内置生日悖论离线工程，标明非实时 AI。
- 创建时可选目标时长，系统按实际配音时长为每个镜头留出足够时间，目标不足时不会截断旁白；节拍对齐、帧率取整可能导致结果与目标有偏差。每个镜头可编辑标题、旁白、画面内容及部分动画参数；支持本地保存、查看作品、下载 MP4 / SRT / 工程 JSON。
- 浏览器路径使用受控 Canvas 组件、Playwright + Chromium 和 FFmpeg 逐帧渲染，提供 540p / 15fps 预览与 1080p / 30fps 正式模式；轻量 Pillow 兜底仍为 540p / 12fps，不能使用音乐；它支持的组件较少，遇到不支持的镜头会提示改用浏览器。在线配音以实际音频长度安排镜头；无配音按文字长度估时。
- 可以上传 MP3 / WAV（最长 5 分钟、25 MB），估计 BPM 和节拍峰值，驱动图形强调与部分镜头边界；支持混合旁白及音乐、调整音乐音量。节拍是估计值，需要人工复核。
- 可根据镜头规划生成图片或短视频，下载到项目并作为程序动画的背景；失败可回退。可预览单镜头、调用模型优化声明式镜头、对预览的三张关键帧进行视觉审查；后两项需联网。重新合成时，浏览器渲染会在内容、时间轴等条件不变时复用镜头与配音。
- 编剧、导演、单镜头优化和审片分别使用针对职责的提示词。导演只能选择现有声明式动画组件；`animation.action` 是设计说明，不会自动变成自由动画。支持双轨分化、洛伦兹轨迹、逐级放大、状态对照、基于给定参数的复利曲线，以及独立等概率抽取的不重复概率推演；可用受限关键帧控制画面位移、缩放、透明度并选择节拍吸附；点阵与关系网络的单个节点可编辑受限直线运动，连线跟随节点；AI 规划出现缺数据或含负值的图表时会尝试调用一次文本模型修正，仍有问题则提示修改。旧项目会在渲染或预览时尝试迁移可识别的画面类型。
- 生成方案时还没有上传音乐，模型并未听到音乐，也无法规划真实小节；节拍分析在上传后进行，当前只用于部分视觉强调和镜头边界，不等同于完整的音乐剪辑。改进提示词不能突破组件数量、单镜头口播和渲染引擎的限制，也不保证达到任何参考成片的质量。
- 不执行 AI 写出的自定义代码；Kimi 优化的是可校验的声明式组件，不能承诺任意新动画。尚无参考视频上传分析、审查后自动修复、精确词级对齐、云端体验码、账号和远程协作。视觉审查不能替代事实核查。详见 [模型与媒体流程](docs/models.md) 和 [动画与音乐实现](docs/animation.md)。
- 渲染时长和内存占用尚待实测，2GB 服务器不建议承担多个渲染；默认绑定本机，适合评委各自在自己电脑运行。
- 若服务在渲染中意外退出，该任务状态不会自动恢复，可重新点击生成。一次只能运行一个渲染或预览任务，关闭页面不会主动取消任务；渲染时可主动取消，正在进行的网络请求或音视频合成步骤结束后停止，分镜规划和单镜头预览暂不支持取消。新渲染进行中、失败或取消后仍可预览和下载上一次成功的成片；若此前已修改项目，该成片不反映最新修改。

## 项目结构

`app/director.py` 模型与分镜校验；`app/scene_spec.py` 结构化场景；`app/browser_render.py` 浏览器逐帧渲染；`app/render.py` 轻量兜底；`app/audio.py` 节拍估计；`app/main.py` API、存储与任务；`web/` 本地工作台；`examples/birthday.json` 离线示例。`data/` 是本机项目和成片，不进入 Git。

参考视频和其中音乐没有放入仓库。运行环境需要在本地或容器提供中文字体；容器安装 Debian 的 Noto CJK 字体包。请在发布前根据实际使用的模型、音频服务和素材检查相应授权与条款。
